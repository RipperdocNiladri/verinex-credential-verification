11. VERIFICATION ENGINE
==================================================

Implement a transparent rule-based verification engine for the MVP.

Do NOT claim that the prototype has a perfect AI fraud detector.

Calculate a Trust Score from multiple verification signals.

Example scoring model:

Certificate ID found and matched: +20
Institution matched: +20
Student/credential data matched: +15
QR matched: +15
Document hash matched: +20
Date/metadata consistency: +5
No detected anomalies: +5

Maximum = 100

The exact scoring logic should be clearly documented in the code.

Allow the scoring system to be modified later.

12. ANOMALY / TAMPER ANALYSIS
==================================================

For the MVP, implement transparent heuristic checks rather than pretending to have a production-grade AI forgery detector.

Possible checks:

- Missing expected fields
- OCR inconsistencies
- Credential ID mismatch
- Institution mismatch
- QR mismatch
- Hash mismatch
- Suspicious metadata where available
- Unusual document structure
- Extremely low OCR confidence if available

Return findings with severity:

LOW
MEDIUM
HIGH

Example:

{
  "type": "HASH_MISMATCH",
  "severity": "HIGH",
  "message": "Uploaded document hash does not match the registered credential."
}
